Headline Optimiser

Stored only in this Chrome profile. Never synced.

API key

Get one at console.anthropic.com → API keys. It's stored only in this Chrome profile and sent only to api.anthropic.com.

Page fields

The ID, name or visible label of the field that holds the article, separated by commas. Different forms use different names: the default Enter_Body, Body, Description covers the standard, News and Exam forms. The first field with article text is used. If none matches, the extension reads the largest editor on the page.

If set, the extension reviews the current headline, and each suggestion gets a Use button that fills this field.

Theme

Day is the pink kitten theme; night is the dark theme. Changes apply straight away. The sun/moon button in the popup switches too.
